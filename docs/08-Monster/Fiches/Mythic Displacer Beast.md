# Mythic Displacer Beast

This terrifying predator is an old Displacer Beast, larger than his kinds. His illusions and brute force are a nightmare for the unfortunate souls who find themselves chosen as his prey.

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

__Armor Class__ 15 (natural armor) \
__Hit Points__ 137 (14d10+60) \
__Speed__ 40ft.

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

  STR  |  DEX  |  CON  |  INT |  WIS  |  CHA
:-----:|:-----:|:-----:|:----:|:-----:|:----:
22 (+6)|14 (+2)|18 (+4)|10 (+0)|14 (+2)|12 (+1)

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

__Senses__ darkvision 60ft., acrobatic +4, athletism +4, passive perception 13\
__Languages__ Elvish Sylvan\
__Challenge__ 6 (2500xp)

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

__Avoidance__ : If the displacer beast is subjected to an effect that allows it to make a saving throw to take only half damage, it instead takes no damage if it succeeds on the saving throw, and only half damage if it fails.

__Mirror Illusion__ : The displacer beast projects a magical illusion that makes it appear to be standing near its actual location, causing attack rolls against it to have disadvantage. If it is hit by an attack, this trait is disrupted until the end of its next turn. This trait is also disrupted while the displacer beast is incapacitated or has a speed of 0.

<span style="color:Maroon; font-size:22px">__Actions__</span>
<hr style="border-bottom:1px solid Maroon; margin:-10px 0 15px">

__Multiattack__ : The displacer beast makes three attacks, one bite and two with its tentacles.

__Bite__ : Melee Weapon Attack: +8 to hit, reach 5 ft., one target. Hit: <span style="color:lightslategrey">13 (2d8 + 4) piercing damage</span>. On a hit, the target must succeed a wisdow saving throw DC 16 or start <span style="color:firebrick">bleeding</span>.

__Tentacle__ : Melee Weapon Attack: +10 to hit, reach 10 ft., one target. Hit: <span style="color:lightslategrey">22 (4d6 + 8) bludgeoning damage</span> + <span style="color:lightslategrey">14 (4d6) piercing damage</span>.

<span style="color:Maroon; font-size:22px">__Bonus Actions__</span>
<hr style="border-bottom:1px solid Maroon; margin:-10px 0 15px">

__Greater Displacement__ : The displacer beast teleport itself and one optional target in 10ft from it at a visible location in 60ft from it. The target takes <span style="color:hotpink">2d8 psychic damage</span>.\
An illusion of the beast stay at the start location and can make opportunity attacks. The illusion disapear at the start of the next beast's turn.

__Illusory Duplication__ : The displacer beast create an Illusion copy of itself. This copy can attacks and make opportunity attacks, replacing <span style="color:lightslategrey">damages</span> by <span style="color:hotpink">psychic damages</span>. It has 1 hit point and an AC of 13.
