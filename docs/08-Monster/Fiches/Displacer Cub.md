# Displacer Cub

Smaller and weaker form of a Displacer Beast. If you see one, an adult see you too.

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

__Armor Class__ 11 (natural armor) \
__Hit Points__ 34 (4d10+12) \
__Speed__ 30ft.

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

  STR  |  DEX  |  CON  |  INT |  WIS  |  CHA
:-----:|:-----:|:-----:|:----:|:-----:|:----:
14 (+2)|12 (+1)|12 (+1)|4 (-3)|10 (+0)|4 (-3)

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

__Senses__ darkvision 60ft., stealth +8, acrobatic +2, passive perception 10\
__Languages --__\
__Challenge__ 1 (200xp)

<hr style="border-bottom:4px solid Maroon; margin:15px 0 15px">

__Avoidance__ : If the displacer cub is subjected to an effect that allows it to make a saving throw to take only half damage, it instead takes no damage if it succeeds on the saving throw, and only half damage if it fails.

<span style="color:Maroon; font-size:22px">__Actions__</span>
<hr style="border-bottom:1px solid Maroon; margin:-10px 0 15px">

__Multiattack__ : The cub makes two attacks : one with its bite, and one with both his tentacles.

__Bite__ : *Melee Weapon Attack* : +4 to hit, reach 5ft., one target. *Hit* <span style="color:lightslategrey">4 (1d4+2) piercing damages</span>.

__Tentacles__ : *Melee Weapon Attack* : +4 to hit, reach 5ft., one target. *Hit* <span style="color:lightslategrey">9 (2d4+4) bludgeoning damage</span>.

__First Illusion__ : As an action, the cub can summon an illusion of itself in a 60ft range. When creating this illusion, it can define movements the illusion will do (lick it's paw, run in circle, sleep...). It can also use __Meow__ from his illusion.

<span style="color:Maroon; font-size:22px">__Bonus Actions__</span>
<hr style="border-bottom:1px solid Maroon; margin:-10px 0 15px">

__Meow__ : The cub can meow, and all enemies in a 30ft range from it :\
In combat : must succeed a wisdom saving throw DC 12 or the next attack roll or DC targeting them benefits from +5.\
Outside combat : should investigate the noise.
